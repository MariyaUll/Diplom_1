## Задание 1: Юнит-тесты

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

Автотесты реализуют проверку логики сборки бургера: добавление/удаление/перемещение ингредиентов, работу с булками, взаимодействие с базой данных и валидацию данных. Тесты изолированы, используют моки там, где это уместно, и покрывают граничные случаи (пустой бургер, некорректные данные, отсутствие ингредиентов и т. д.).

### Реализованные сценарии

Созданы юнит-тесты, покрывающие классы `Bun`, `Burger`, `Ingredient`, `Database`

Процент покрытия 100% (отчет: `htmlcov/index.html`)

Скрипт точки входа (praktikum/praktikum.py) исключён из расчёта покрытия, так как является демонстрационным сценарием, а не реализацией логики.

### Структура проекта

Diplom_1/
├── praktikum/                          # Пакет, содержащий код программы
│   ├── __init__.py                     # Делает папку пакетом Python
│   ├── bun.py                          # Класс булки (Bun)
│   ├── burger.py                       # Класс бургера (Burger): сборка, перемещение и удаление ингредиентов
│   ├── ingredient.py                   # Класс ингредиента (Ingredient)
│   ├── database.py                     # Класс работы с БД (Database): получение доступных булок и ингредиентов
│   └── praktikum.py                    # Точка входа: демо-скрипт сборки бургера (исключён из покрытия)
├── tests/                              # Пакет, содержащий тесты, разделенные по классам. Например, `bun_test.py`, `burger_test.py` и т.д.
│   ├── __init__.py                     # Делает папку пакетом Python
│   ├── test_bun.py                     # Юнит-тесты для класса Bun
│   ├── test_burger.py                  # Юнит-тесты для класса Burger
│   ├── test_ingredient.py              # Юнит-тесты для класса Ingredient
│   └── test_database.py                # Юнит-тесты для класса Database
├── conftest.py                         # Фикстуры
├── constants.py                        # Константы 
├── pyproject.toml                      # Конфигурация проекта: настройки coverage (включая omit для praktikum.py)
├── requirements.txt                    # Зависимости проекта
└── README.md                           

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов и создание HTML-отчета о покрытии**

Запускать нужно из папки Diplom_1

>  `$ pytest --cov=praktikum --cov-report=html`
